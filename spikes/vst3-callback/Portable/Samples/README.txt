PORTABLE WAV SAMPLES - version 0.4.60

These six tiny synthetic diagnostic WAVs were generated by
tools/generate-sample-fixtures.py, not taken from a commercial sample pack.
They are offered under CC0-1.0: https://creativecommons.org/publicdomain/zero/1.0/
You may copy, change and redistribute the diagnostic audio, including commercially.
The plugin/source and upstream FoxDot patches retain their own existing licenses.

Folder names match FoxDot's symbol mapping:
  x/lower/*.wav        x = kick
  o/lower/*.wav        o = snare
  _/hyphen/*.wav       - = closed hat, NOT a rest
  a/lower/*.wav        a = test chirp (your own sounds can replace it)
  a/upper/*.wav        A = a separate, uppercase bank
Alphabetic Samples/x/*.wav is also accepted as a simpler fallback.
Put your own WAVs in these folders, sorted by filename; sample= chooses an
index and wraps in either direction. Spaces in play("x o ") are rests.
sample= and rate= accept var()/linvar() changes. Sample selection is discrete:
linvar switches to the nearest selected WAV halfway through each segment; no
crossfade is attempted. Use var() to switch between forward/reverse playback.
linvar rate values must keep one sign and stay 0.0625..8 to avoid zero-speed playback.
Sample play strings support FoxDot-style nested groups: `[--]` divides the
contents evenly inside one step; `(xo)` laces one item per successive pattern
cycle; `{xo}` selects among its choices in a bounded eight-cycle variation;
adjacent `<x  ><-  >` groups layer matching positions. Group nesting is limited
to 8 levels and the expanded pattern to 256 slots. Random choices are compiled
when Run is pressed and vary across the eight-cycle pattern, then repeat until
the next Run. The compatibility checker reports malformed syntax. FoxDot
per-hit sample selection uses a bar-enclosed pair such as `|x1|`: one sample
symbol followed by one digit from 0 to 9. It chooses that index for just the
selected hit; ordinary hits continue using the `sample=` pattern. General
Sample P patterns can be written as finite one-character sequences, e.g.
`P["x", "o", " "]`. `.reverse()` and `.rotate(n)` transform those symbols;
`|` concatenates two sample patterns left-to-right, and can be followed by a
transform such as `.rotate(2)`. `PAlt(pattern1, pattern2, ...)` cycles the
patterns to their least-common-multiple length and alternates their symbols.
Each input and expanded output is limited to 256 items. `PStretch(pattern, n)`
cycles a sample sequence to length `n`; `PStutter(pattern, counts)` repeats
each item by a whole-number scalar or cyclic count pattern from 0 to 16. Use
`sample=` for WAV variant choice. Numeric source patterns, P arithmetic and `&` zipping are
not supported for sample symbols: FoxDot's `&` creates chord groups, but the
sample player accepts one symbol per step.
`PShuf(pattern)` makes a random permutation of a finite sample-symbol pattern,
preserving its rests and duplicate hits.
`PJoin([phrase1, phrase2, ...])` joins sample-symbol phrases left-to-right and
can be composed with PShuf to randomize the complete joined phrase.
`PBeat("x xx")` and `PDur(3, 8)` return bounded duration patterns for pulse
strings and Euclidean rhythms.
`PDelay(3, 8)` returns cumulative beat offsets; `PStrum(4)` returns a stuttered
rhythm-duration pattern.

PCM 8/16/24/32-bit or IEEE float32 WAV, mono/stereo, 8000-192000 Hz.
Stereo inputs are currently downmixed to one mono voice, then player-panned.
rate=1 is natural speed, rate=2 is faster/higher, rate=-1 is reverse.
Rate magnitude is limited to 0.0625..8 for this initial safe implementation.
dur controls rhythm. A sample plays to its natural end unless sus crops it.
There is no pitch-preserving time stretching, stream-from-disk or recording yet.

Files load on the script worker, never in the audio callback, and are cached
for this engine instance. Reopen the plugin after changing an already cached
WAV. Cache budget: 128 MiB decoded mono data; file limit: 64 MiB each.
Errors leave the existing players unchanged. Current per-player polyphony
limits still apply to overlapping sample tails. No external SC server, OSC,
libsndfile DLL or newly compiled UGen module is needed.
