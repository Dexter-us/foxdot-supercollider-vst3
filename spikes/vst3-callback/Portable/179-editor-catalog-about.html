Dexter U.S. FoxDot editor catalog

This About page opens from the Synths or Effects list. It describes what each entry inserts and what it needs. Catalog edits change the script, not the running audio; click Run to apply. You can also drag an available row onto a p1 >> through p8 >> line. Right-click a row for Insert at editor caret or About this item.

Built-in sounds run in the VST's local engine. There is no SuperCollider server or sclang process. A precompiled .scsyndef is a synth/effect definition, not a loader for additional UGen DLLs. Optional UGens need their matching plugin module installed and the DAW restarted.

Instruments

The menu groups the bundled calls by family. The labels map to functions accepted by the embedded Python API; “square” is shown as its actual call name, pulse. To create a new voice, right-click an empty p3 >> line, or drag a catalog item onto that line. A small starter pattern is inserted so it can run immediately.

Bundled calls: ambi, arpy, bass, bell, blip, bug, charm, creep, crunch, dab, dbass, dirt, donk, dub, feel, fuzz, glass, gong, growl, jbass, karp, keys, klank, lazer, marimba, noise, nylon, orient, pads, pasha, pluck, prophet, pulse, quin, rave, razz, ripple, saw, sawbass, scatter, scratch, sine, sinepad, sitar, snick, soft, soprano, space, spark, squish, star, swell, triangle, twang, varsaw, viola, zap.

Waveforms contains sine, saw, pulse (including the square alias) and triangle.

play is the WAV sample player and is listed separately. It keeps its sample-string syntax. External precompiled SynthDefs appear as userSynth("Name", ...) entries. Select a custom SynthDef from a blank player line; don't replace a sample-pattern or existing custom-player call with an ordinary pitched synth.

Loaded player-effect SynthDefs

Only effects already loaded into the VST appear as insertable. Unavailable optional entries remain visible for information but cannot be inserted until the matching SynthDef/UGen pack is installed and the host restarted. Loaded player effects include Airwindows TapeDelay2 and Echojam, Chorus, Flanger, Phaser, Tremolo, JPverb, Greyhole, and optional LimutFX inserts such as LimutShifter, LimutShimmer, and LimutGatedVerb. A chain may contain up to four inserts. Use effects=[("Chorus", {"fx_mix": 0.4}), ...] for a chain or the legacy effect="Chorus", fx_mix=0.4 form for one insert when that effect exposes fx_mix. Airwindows Echojam and TapeDelay2 do not: use their effect-specific controls instead.

Insert, drag, and edit

  1. Type p3 >> and right-click that line, or drag an available Synths/Effects row onto it.
  2. A new voice starts as a small sine pattern. Selecting an instrument or effect on an existing supported player edits its call/chain.
  3. Right-click a sidebar row and choose About to jump to its details here.
  4. Changes are code edits only. Click Run to execute; Undo reverses the catalog insertion. A four-insert chain limit is enforced.
