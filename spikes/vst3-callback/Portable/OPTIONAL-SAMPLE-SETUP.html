Dexter U.S. FoxDot · Windows VST3

Add your own sample sounds

Keep a large sample library out of the plugin download. Download a WAV pack separately, place its files in the portable folder, and the plugin can use them by FoxDot-style sample symbol.

The plugin does not download audio automatically. The bundled six tiny diagnostic WAVs are only a basic test kit. A larger library is optional; this guide contains no third-party audio.

1. Get a sample pack you are allowed to use

  1. Choose a source that supplies WAV files and whose license permits your intended use.
  2. Download the archive from that source and extract it on your computer. Do not put the ZIP file itself in the Samples folder.
  3. Keep the pack's license and attribution notes with your copy. Do not redistribute the audio unless its terms allow it.

One community reference is joenio/foxdot-sounds. Its README describes a GPLv3 sample pack and points to Debian packaging sources, but the GitHub repository currently contains the README rather than WAV files. Check the current source availability and license yourself; this link is information, not a direct WAV download.

2. Copy WAV files into the plugin's Portable folder

The folder belongs inside the VST3 bundle, next to Contents:

dexter_sc_tone.vst3\
├── Contents\
└── Portable\
    └── Samples\
        ├── x\
        │   └── lower\
        │       ├── kick_01.wav
        │       └── kick_02.wav
        ├── o\
        │   └── lower\
        │       └── snare_01.wav
        └── _\
            └── hyphen\
                └── hat_01.wav

In this example, the full path is dexter_sc_tone.vst3\Portable\Samples\x\lower\kick_01.wav. Keep the plugin bundle and its Portable folder together.

3. Match a folder to the symbol in your code

Code symbolFolder under Portable\SamplesTypical use
xx\lower\Kick
oo\lower\Snare
-_\hyphen\Closed hat; it is not a rest
a / Aa\lower\ / a\upper\Separate lowercase and uppercase banks
Any other letterletter\lower\ or letter\upper\One folder per letter bank

Other supported symbols use these named folders under Portable\Samples\_:

& → ampersand    * → asterix      @ → at
^ → caret         : → colon         $ → dollar
= → equals        ! → exclamation   / → forwardslash
# → hash          - → hyphen        % → percent
+ → plus          ? → question      ~ → tilde
\ → backslash     1 → 1             2 → 2
3 → 3             4 → 4

For example, a file for & goes in Portable\Samples\_\ampersand\. Spaces in a play string are rests and do not need a sample file.

4. Use and refresh the samples

  • Place one or more .wav or .wave files in the symbol's folder.
  • Files are sorted by filename: sample=0 selects the first, sample=1 the second, and so on. Zero-padded names such as kick_01.wav keep the order predictable.
  • Example: p1 >> play("x-o-", sample=0).
  • Close and reopen the plugin after adding or changing a WAV; loaded audio is cached for the current plugin instance.
Supported WAVs: PCM 8/16/24/32-bit or IEEE float32; mono or stereo; 8–192 kHz; no more than 64 MiB per file. Decoded sample cache is limited to 128 MiB. Stereo is downmixed to mono before player panning.
Optional files stay on your computer and are not required in a redistributed plugin ZIP. The plugin bundle still includes its six small CC0 diagnostic WAVs unless a package explicitly omits them. Sample source licenses are separate from the plugin's and FoxDot's code licenses.
