AntiAliasingOscillators / BlitB3Saw isolated compatibility probe
================================================================

This is a test-only addition for Dexter v0.4.176. It reuses the precompiled
Windows x64 AntiAliasingOscillators.scx from the user's SC3plugins 3.14.1
Windows archive; this project does not rebuild SuperCollider or this UGen.
Example 221 pairs it with BlitB3SawProbe.scsyndef and a bounded leak slider.

Install/verify:
1. Merge AntiAliasingOscillators.scx into the existing Portable/SCPlugins
   folder and the matching BlitB3SawProbe files into Portable/SynthDefs.
2. Fully close and reopen the DAW so the module is loaded at startup.
3. Run Portable/221-antialiasing-oscillator-probe.py and listen for a saw tone.
4. If it plays, move the leak slider in Players to confirm the sidecar control.

This tests the existing precompiled module against the VST's pinned
SuperCollider engine. A Windows CI/validator pass confirms loading and
SynthDef registration; listening in a DAW is still needed to confirm audible
behavior on the user's host. Keep the existing SynthDefs and UGen files.
