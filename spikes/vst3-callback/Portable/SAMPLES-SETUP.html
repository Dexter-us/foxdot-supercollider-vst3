Portable WAV samples

Dexter U.S. FoxDot · version 0.4.79

This guide explains how to add your own legally licensed WAV files without including the demo samples in your plugin update.

Where the files go

Inside the VST3 bundle, create or use Portable/Samples. Keep the folder next to the bundle’s Contents folder:

Dexter U.S FoxDot.vst3/
├── Contents/
└── Portable/
    └── Samples/
        ├── x/
        │   └── lower/
        │       └── 00-kick.wav
        ├── o/
        │   └── lower/
        │       └── 00-snare.wav
        └── _/
            └── hyphen/
                └── 00-hat.wav

For a portable install, use the bundle’s existing Portable folder. If the bundle is under Program Files, Windows may require administrator permission to add files; install a per-user copy or approve the file operation rather than changing the plugin path.

Change the slice per hit

start and end are normalized positions in each WAV. They accept numbers, finite P[...] or list patterns, and var()/linvar(). Each hit must resolve to 0 ≤ start < end ≤ 1; the loop option remains a fixed Boolean.

p1 >> play("x-o-", start=P[0.0, 0.2], end=P[0.5, 0.9])
p2 >> play("x", start=linvar([0.1, 0.3], 4),
          end=linvar([0.7, 0.9], 4))

Example 101 in this folder demonstrates per-hit patterns and time-varied slices alongside Example 100’s fixed slice and bounded loop.

Match folders to play symbols

  • x/lower/ contains sounds triggered by x.
  • o/lower/ contains sounds triggered by o.
  • _/hyphen/ contains sounds triggered by -; a space is a rest.
  • a/lower/ is the lowercase a bank; a/upper/ is the uppercase A bank.
  • Other letter symbols use their matching letter folder. The simpler Samples/x/*.wav layout is also accepted for letters.

Put alternate hits in the same symbol folder and name them so they sort in the desired order, such as 00-kick.wav and 01-kick-soft.wav. Indexes start at zero: sample=0 picks the first sorted file, sample=1 the second. A per-hit marker such as |x1| selects the second x sample just for that hit.

Use a properly licensed WAV

Download or export a WAV from a source whose license permits your intended use, and keep its attribution/license terms if required. No third-party sample pack is included or endorsed by this guide. The plugin accepts PCM 8/16/24/32-bit or IEEE float32 WAV, mono or stereo, at 8–192 kHz; files are limited to 64 MiB each. Stereo is downmixed to mono before player panning.

To use your own samples instead of the demo sounds, replace the matching files under Portable/Samples or add a new symbol folder. The demo files are optional and separately licensed CC0.

Try it in the editor

Clock.bpm = 90
p1 >> play("x-o-", dur=0.5, sample=0, amp=0.3)

For a bounded slice, use normalized positions from 0 to 1. A loop stops at sus=, or at dur= when sus is omitted:

p1 >> play("x", dur=2, start=0.15, end=0.55, loop=True, sus=1.8)

After changing a WAV that the current plugin instance has already loaded, close and reopen the plugin so its in-memory sample cache is refreshed. The player does not read samples from disk in the audio callback.

Keeping the update small: you can omit the Portable/Samples demo folder from an update package and add only the legal WAVs you need. Keep the Portable/Samples directory structure shown above; the portable scripts and sample files can be managed separately.
